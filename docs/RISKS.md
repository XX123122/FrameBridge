## 固定允许的机制

- 使用用户后续指定的可见 Edge，也支持用户另行指定的 Chrome。网页账号可以与 Codex 账号不同，生成发生在选定网页会话；不迁移账号或凭证。当前缺少浏览器连接，Python CDP 适配器作为固定可选路径。
- Python 仅接入用户明确指定的本机 CDP 端口和一个明确页面，不发现其它账号、不扫描端口、不复制浏览器 profile。
- 单个空白对话、一次发送；只使用当前唯一新 assistant 的图像/画布和正常 Download/Save 控件。没有 URL fetch、CDP resource、网络响应提取、私有图片模型调用或截图充当生成文件。
- 用户自行登录。浏览器自身保存登录会话属于浏览器正常机制；Python 不读取、复制或导出任何认证信息。

## 必须停止

验证码、Cloudflare、安全验证、可识别的额度/权限提示、平台拒绝、控件不唯一、上传无法确认、页面结构变更、多个生成结果、网络失败和观察超时都会停止。UI 检测不是绝对可靠的；代码没有绕过或自动解决验证的步骤。不要因为检测漏掉一句新提示就重复发送。

本地 stop 或 Ctrl+C 不保证远端请求停止，用户应在原页面确认是否还在生成。恢复不会重新点击发送。等待上限为 600 秒，没有无限重试或自动 drain 队列。手动关闭待确认任务后，另建任务也是新的授权请求，不能把它当成自动重试策略。

## CDP 与当前会话

本机 CDP 提供浏览器控制能力，应只在本机使用，不绑定公网、不转发、不共享地址。助手不自动打开调试端口或修改扩展安全权限。用户自愿配置时，不要给程序浏览器 profile 文件、Cookie 导出、密码或 OAuth Token。

Chrome 136 起，普通默认 user-data-dir 不再支持相同的 remote debugging 开关用法，需要非默认目录；这意味着新建 CDP 浏览器通常需要用户重新登录，不能宣称自动复用现有普通 Chrome 的登录。[Chrome 官方说明](https://developer.chrome.com/blog/remote-debugging-port)

需要保留原普通 Chrome 会话时，应使用已安装并由用户连接的 Codex Chrome 扩展路径；不要迁移 Cookie。当前检查没有找到已连接 Chrome 或运行的 Chrome 窗口，也未在标准安装目录找到可执行文件；不能据此断言磁盘其它位置一定没有 Chrome。

当前实际选择为 Edge。原普通 Edge 没有调试参数；用户明确授权独立会话后，助手使用 `scripts/start_edge.ps1` 启动可见 Edge，127.0.0.1:9222 已监听，用户自行登录。没有关闭原窗口、复制 profile 或改变安全策略。[微软接入说明](https://learn.microsoft.com/en-us/microsoft-edge/devtools/protocol/)支持指定调试端口和单独会话目录。默认 profile 的调试限制尚未验证；当前固定使用已获用户授权的独立会话，不尝试绕过默认 profile 或组织策略限制。

## 输出与隐私

实际扩展名、完整像素解码、最短边 ≥256、最长边 ≤8192、单帧、最多 3200 万像素、文件 ≤64MiB 及 SHA-256 都会检查。这些是本地合理性阈值，不是模型规格。技术校验无法保证人物身份、角色或艺术质量正确，最终需用户视觉检查。某些模型会改写输入或忽略角色约束，本项目不能保证模型行为。

原始 Prompt、参考图快照与任务日志保存在本地。只上传显式参考图，不上传项目、日志或 tasks.json。不要将个人任务文件加入公开 Git 仓库；默认忽略输出、参考图、日志与本地 tasks.json。原始 Prompt 文件本身也可能敏感，公开提交前需自行检查。

输出写入使用 exclusive create，不覆盖已有文件。崩溃后可能保留不完整输出，需要人工检查；程序不会自动删除它或覆盖重写。每次状态保存为原子替换，进程锁阻止同时修改 ledger；tasks.json 是权威状态，logs 的 task.json 是派生镜像。镜像写入失败时检查 tasks.json，不重复生图。
