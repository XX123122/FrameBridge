# Demo assets

Directory reserved for real, reviewed and approved public demo media. **Currently no video/GIF/poster is approved or included.**

Follow [DEMO_RECORDING.md](../DEMO_RECORDING.md). Store only nonsensitive exports with provenance and media rights. Do not copy private browser screenshots/logs, author account data or reference images here. Avoid unnecessary third-party character/brand assets; a generic example is easier to review. Mocked UI tests remain under tests/, not here.

For each future asset, record filename, date, source task/version, whether real or illustrative, edits/redactions, license/consent, and accessible alt text. Do not create a fake software-run GIF.
